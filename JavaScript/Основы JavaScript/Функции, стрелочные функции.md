## Замыкание функции

<mark class="hltr-b">Замыкание функции</mark> - это сама функция вместе со всеми переменными, которые ей доступны.

```js
let num = 20;

function showFirstMessage(text) {
	console.log(text);
	console.log(num);
}

showFirstMessage('Hello World!');
console.log(num);
```

## return

<mark class="hltr-b">return</mark> позволяется вернуть результат из функции и прекратить саму функцию.

```js

function calc(a, b) {
	return(a + b);
}

console.log(calc(4, 3));
console.log(calc(5, 6));
console.log(calc(10, 6));
```


```js
function ret() {
	let num = 50;
	
	return num;
}

const anotherNum = ret ();
console.log(anotherNum);
```

## Классификация функций

### function delaration

```
function foo() {
	код
}
```

Создается до начала выполнения скрипта, можно вызвать перед объявлением.
### function expression

```
let foo = function() {
	код
}
```

```js
const logger = function() {
	console.log('Hello');
}

logger();
```

Создается только тогда, когда доходит поток кода, можно вызвать только после объявления.

### Стрелочные функции

```
() =>
```

Не имеет своего контекста (this).

```js
const calc = (a, b) => {return a + b};

const calc = (a, b) =>  a + b;
```


## Использование функций и аргументов

```js
const usdCurr = 28;
const eurCurr = 32;

function convert(amount, curr) {
	console.log(curr * amount);
}

convert(500, usdCurr);
convert(500, eurCurr);
```

## Использование return в функциях 

```js
const usdCurr = 28;
const discount = 0.9;

function convert(amount, curr) {
	return curr * amount;
}

function promotion(result) {
	console.log(result * discount);
}

const res = convert(500, usdCurr);
promotion(res);
```
