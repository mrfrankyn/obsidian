
## Количество символов (.length)

```js
const str = 'test';

console.log(str.length);
```

## Количество элементов внутри массива (.length)

```js
const arr = [1, 2, 3];

console.log(arr.length);
```

## Получение символ по индексу в строке


```js
const str = 'test';

console.log(str[2]);
```

## Метод изменения регистра для строки

```js
const str = 'test';

console.log(str.toUpperCase());
```

```js
const str = 'TEST';

console.log(str.toLowerCase());
```
## Поиск под строки

Если есть искомая строка
```js
const fruit = 'Some fruit';

console.log(fruit.indexOf('fruit'));

```

Если отсутствует искомая строка
```js
const fruit = 'Some fruit';

console.log(fruit.indexOf('q'));
```

## Обрезание строки

```js
const logg = 'Hello world people';

console.log(logg.slice(6, 11));
//slice(Индекс от, Индекс до) 

console.log(logg.slice(6));
//slice(Индекс от), происходит обрезание до конца строки 

console.log(logg.substring(6, 11));
//substring(Индекс от, Индекс до) 

console.log(logg.substr(6, 5));
//substring(Индекс от, Количество символов) 

```

## Округление числа до ближайшего целого

```js
const num = 12.2;

console.log(Math.round(num));

```


## Преобразование строки в число до целого числа

```js
const test = '12.2px';
console.log(parseInt(test));
```

## Преобразование строки в число с дробью

```js

const test = '12.2px';
console.log(parseFloat(test));

```
