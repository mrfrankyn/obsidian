# Объекты

Делятся на **Спец. объекты** и **обычные объекты**

Спец объекты делятся на:

- Массив
- Функции function
- Объекты Даты
- Регулярные выражения
- Ошибки

## Объекты

Данные которые содержит объект - это **свойства объекта**. Действия объекта - **методы объекта**.

```
const obj = {
	name: 'John',
	age: 25,
	isMarried: false
};
```

## Массив

**Массив** - это частный случай объекта.
```
let arr = ['plum.png', 'oragen.png', 6];

```
