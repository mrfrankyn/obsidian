
# Массив:
## Вывод информации
```
const arr = [1, 2, 3];
console.log(arr[1]);
```
Выводится: 2

# Объект:
## Вывод информации
```
const obj = {
	map: 500,
	map1: 800
};

console.log(obj.map);
```
Выводится: 500

## Добавление нового свойства
```
1ый вариант:
const obj = {
	map: 500,
	map1: 800
};

obj.map2 = 300;

console.log(obj['map2']);

2ой вариант:
const obj = {
	map: 500,
	map1: 800
};

obj['map2'] = 300;

console.log(obj['map2']);
```
Выводится: 300
