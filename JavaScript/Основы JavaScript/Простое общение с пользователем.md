## alert

Предупреждение пользователя
```
alert('Hello world');
```
## confirm

Получение подтверждения от пользователя на вопрос
```
const result = confirm('Are you here?');
```
В результате подтверждения от пользователя, то возвращается boolean результат. Если Ок, то true, иначе false.
## prompt

Для того чтобы пользователь указал определенное значение.
```
const answer = prompt('Вам есть 18?', '18');

prompt('Текст', 'значение по умолчанию')
```
Пользователю отображается мод. окно для ввода значения. 
![[Pasted image 20260109231018.png]]
Результат введенный пользователям всегда выводится в типе данных `string`.

## Сохранение данных в массив

```
const answers = [];

answers[0] = prompt('Как ваше имя?', '');
answers[1] = prompt('Как ваше фамилия?', '');
answers[2] = prompt('Сколько вам лет?', '');

document.write(answers); - Для перезаписывания документа и вывода информации (не используется в проектах)
```
