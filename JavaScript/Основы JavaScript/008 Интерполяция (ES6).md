==Интерполяция== - означающая что внутри строки можно вставлять значение переменной.

```js
const category = 'toys';

console.log(`https://someurl.com/&{category}/5`);
```

==Конкатенации строк== - это когда берется разные строки и склеиваются между друг другом
Пример:
```js
const category = 'toys';

console.log('https://someurl.com/' + category);
```
