## Логический оператор И (&&)

Запинается на лжи

```
const hamburger = true;
const fries = true;

if (hamburger && fries) {
	console.log('Я сыт!');
}

**Выводится**: Я сыт!
```

```
const hamburger = true;
const fries = true;

if (hamburger && fries) {
	console.log('Я сыт!');
}

console.log((hamburger && fries));

**Выводится**: Я сыт!
```

true

==Динамическая типизация==, 5 сущностей, которые имеет значение false:
- 0
- Пустая строка
- null
- undefined
- NaN
Все остальные сущности имеют значение true.

```
const hamburger = 2;
const fries = 1;

if (hamburger === 3 && fries) {
	console.log('Все сыты!');
} else {
	console.log('Уходим');
}
```

```
const hamburger = 2;
const fries = 1;
const cola = 0;

console.log(hamburger === 3 && cola && fries);

Вернется: 0
```

```
console.log(1 && 0);
Вернется: 0

console.log(1 && 5);
Вернется: 5, так как возвращается любое положительное значение

console.log(null && 5);
Веренся: null

console.log(0 && 'dwda');
Вернется: 0
```

## Логический оператор ИЛИ (||)

Запинается на правде 

```
const hamburger = 2;
const fries = 0;
const cola = 0;

if (hamburger || cola || fries) {
	console.log('Все сыты!');
} else {
	console.log('Уходим');
}

Выводится: 'Все сыты!'

Выводится первое положительное значение
```
