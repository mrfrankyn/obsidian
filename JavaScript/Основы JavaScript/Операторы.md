## Инкремент  и декремент 

==Инкремент== - увеличивает значение на 1.
==Декремент== - уменьшает значение на 1.

```
let incr = 10,
	decr = 10;
	
incr++;
decr--;
```
В итоге выводится 11 и 9.

`++incr` - это форма записи означает ==префиксной==. Сначала делает математическое вычисление, а потом выводит результат.
```
let incr = 10,
	decr = 10;
	
++incr;
--decr;
```
В результате: 11 и 9

`decr--` - это форма записи ==постфиксной==. Сначала возвращает старое значение, а после делает математическое вычисление.
```
let incr = 10,
	decr = 10;
	
incr++;
decr--;
```
В результате: 10 и 10

## Равно

`=` - формат присваивания.

`==` - формат сравнения.

`===` - строгое равенство, где сравнивает не только значение, но и по типу данных.

## Логические операторы

`&&`- логический оператор ==и==. Работает когда оба выражения являются true.
`||` - логический оператор ==или==. Работает когда одно из выражений является true.

```
const isChecked = true,
	  isClose = true;
	  
console.log(isChecked && isClose);
```
В результате выводится true

```
const isChecked = true,
	  isClose = false;
	  
console.log(isChecked && isClose);
```
В результате выводится false

```
const isChecked = false,
	  isClose = false;
	  
console.log(isChecked || isClose);
```
В результате выводится false

```
const isChecked = true,
	  isClose = false;
	  
console.log(isChecked && !isClose);
```
В результате выводится true
