
<mark class="hltr-b">Прототипирование</mark> **позволяет** наследовать методы и свойства родителя, от которого произошло прототипирование.

```js
"use strict";

const soldier = {
	health: 400,
	armor: 100,
	sayHello: function() {
		console.log('Hello');
	}
};

const jonh = Object.create(soldier);

//const jonh = {
	//health: 100
//}; 

//Object.setPrototypeOf(jonh, soldier);

jonh.sayHello();

```
