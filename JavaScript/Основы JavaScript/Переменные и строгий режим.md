## Объявление переменной
```
let number = 5;
const leftBorderWidth = 1;
```

**let** - переменная изменяемая.
**const** - неизменяемая переменная.

## Строгий режим (use scrict директива)

`"user strict"` - это директива означающая, что используется современный стиль кода. Используется всегда вначале скриптового файла.-
