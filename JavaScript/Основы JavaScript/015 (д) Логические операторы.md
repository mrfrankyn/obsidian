## Логический оператор И (&&)

Запинается на лжи

```js
const hamburger = true;
const fries = true;

if (hamburger && fries) {
	console.log('Я сыт!');
}

```

```js
const hamburger = true;
const fries = true;

if (hamburger && fries) {
	console.log('Я сыт!');
}

console.log((hamburger && fries));
```

==Динамическая типизация==, 5 сущностей, которые имеет значение false:
- 0
- Пустая строка
- null
- undefined
- NaN
Все остальные сущности имеют значение true.

```js

```

## Логический оператор ИЛИ (||)

Запинается на правде 

```js
const hamburger = 2;
const fries = 0;
const cola = 0;

if (hamburger || cola || fries) {
	console.log('Все сыты!');
} else {
	console.log('Уходим');
}
```
