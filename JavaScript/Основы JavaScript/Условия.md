==Альтернативное решение для добавления условия==

Можно использовать только для равно.
```
const num = 50;

switch (num) {
	case 49:
		console.log('wrong');
		break;
	case 100:
		console.log('wrong');
		break;
	case 500:
		console.log('true');
		break;
	default:
		console.log('wrong');
		break;
}
```
